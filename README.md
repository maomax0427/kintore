# キントレ

テキストで書いた筋トレメニューを、そのままセットとレストに組んで記録できるアプリ（Strong風）。

- アプリ: https://maomax0427.github.io/kintore/
- iPhone: Safariで開いて 共有 → ホーム画面に追加

## メニューの書き方

```
【胸の日】
レスト90秒
ベンチプレス 60kg×10×3
インクラインダンベルプレス 20kg 10回 3セット レスト2分
ダンベルフライ 12kg 12,10,8
スクワット
アップ 40kg 10回
80kg 5回
```

レストを書かない場合は、種目と回数から自動で決まります（高重量の複合種目は長め、単関節種目は短め）。

## ファイル

- `parser.js` テキスト → 種目・セット・レスト
- `app.js` 画面、記録、レストタイマー
- データは端末のブラウザ（localStorage）に保存。設定からJSONでバックアップできます。
